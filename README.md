## 🤔 Что это

Рандомайзер учеников для учителей 👩‍🏫

У учителя есть папка с текстовыми файлами — списки классов (каждая строка - фамилия ученика).
Программа выбирает случайного ученика из выбранного списка:

> — Кто пойдёт к доске?
> — _жмяк_ → «Петров»

## ⚙️ Как работает

1. 📂 Выбираешь директорию, где лежат `.txt` со списками классов
2. 📃 Из выпадающего списка выбираешь нужный файл (класс)
3. 🎲 Жмёшь кнопку — `random.nextInt()` показывает жертву
4. 🔁 Можно жать снова

## ✨ Фичи

- Безрамочное окно
- Выбор директории через стандартный диалог
- Чистый, непредвзятый рандом

## 🚀 Запуск
